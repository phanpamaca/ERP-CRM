# ERP & CRM Analytics System (Python + SQL + Power BI)

## 🚀 Overview
This project simulates a real-world ERP and CRM system, analyzing customer behavior, product performance, and revenue trends.

## 🧰 Tech Stack
- Python (Pandas, NumPy)
- SQL (SQLite)
- Power BI

## 📊 Key Features
- Customer segmentation (CRM)
- Order & product analytics (ERP)
- KPI dashboard (Revenue, Orders, AOV)
